# Política de seguridad

Gracias por ayudar a proteger Loopback y a sus alumnos.

## Cómo informar de una vulnerabilidad

**No abras un issue público.** Informa en privado desde la pestaña
[Security → Report a vulnerability](https://github.com/loopback-academia/loopback-academia.github.io/security/advisories/new)
de este repositorio.

Incluye, si puedes:

- qué parte de la web o de la base de datos está afectada;
- los pasos para reproducirlo;
- el impacto que crees que tiene.

Responderemos lo antes posible y te avisaremos cuando esté corregido.

## Alcance

- La web publicada en GitHub Pages y su código en este repositorio.
- Las reglas de acceso de la base de datos (`supabase/migrations/`).

No hagas pruebas que afecten a otros usuarios, borren datos o saturen el servicio, ni intentes acceder a cuentas que no
sean tuyas.
